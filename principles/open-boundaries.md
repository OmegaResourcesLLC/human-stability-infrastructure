# Open Boundaries

A framework should be able to learn from information that challenges its original assumptions.

Human Stability Infrastructure therefore treats conceptual boundaries as open to examination.

If another field already explains a problem better, the framework should learn from that field.

If a local practice works in a way the framework did not anticipate, that practice should be examined rather than forced into existing terminology.

If a question cannot be answered with the available information, the answer should remain open.

The purpose of an open boundary is not endless abstraction. It is to prevent the framework from becoming so attached to its own language that it stops learning.
