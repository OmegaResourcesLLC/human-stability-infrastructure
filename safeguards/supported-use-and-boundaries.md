# Supported Use and Boundaries

Human Stability Infrastructure is published so people can examine, adapt, criticize, test, and improve the ideas.

Some applications are aligned with the current purpose of the project. Others fall outside what the project has been designed or validated to support.

## Uses the project currently supports

The materials may be useful for exploratory research, education, implementation planning, case-conference discussion, coordination review, service-design exercises, workflow analysis, synthetic scenario testing, framework comparison, and structured criticism.

They may also be used as reasoning prompts with AI systems when a qualified human remains responsible for reviewing the output and the shared safeguards are preserved.

## Uses the project does not currently support or endorse

The project does not currently support or endorse using these materials as a validated clinical assessment, predictive risk score, automated eligibility system, sentencing instrument, supervision classification system, punitive tool, surveillance system, diagnostic tool, or autonomous decision maker.

This statement describes the intended and validated scope of the project. It does not add copyright restrictions beyond the licenses governing the repository.

## Adaptations

Adaptation is expected.

If you change the framework substantially, please identify the changes clearly so people do not confuse the adaptation with the original project.

If an adaptation removes safeguards, adds scoring, makes predictions, or introduces consequential automated decisions, it should not be represented as an endorsed Human Stability Infrastructure implementation unless that endorsement has actually been given.
